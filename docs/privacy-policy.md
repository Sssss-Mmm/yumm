yumm(이하 "서비스")은 이용자의 개인정보를 다음과 같이 처리합니다.
**받지 않는 정보는 이 문서에 적지 않았습니다. 여기 없는 항목은 수집하지 않습니다.**

---

## 1. 수집하는 개인정보

### 1-1. 가입 시 (이용자가 직접 입력)

| 항목 | 필수 | 이용 목적 |
|---|---|---|
| 이메일 | 필수 | 로그인 아이디, 계정 식별, 서비스 관련 연락 |
| 비밀번호 | 필수 | 본인 확인. **암호화(해시)하여 저장하며 원문은 보관하지 않습니다** |
| 닉네임 | 필수 | 다른 이용자에게 표시되는 이름 |
| 성별 | 필수 | 매칭의 성별 조건 판정 |
| 출생연도 | 필수 | 만 19세 이상 여부 확인 |
| 프로필 이미지 주소 | 선택 | 다른 이용자에게 표시되는 이미지 |

- **출생연도는 4자리 연도(예: 1998)이며 생년월일이 아닙니다.** 만 19세 이상 여부만 판정하면 되므로 그 이상은 받지 않습니다.
- **전화번호, 실명, 주소, 직장 정보, 결제 정보는 수집하지 않습니다.**
- 약관 동의 사실과 동의 시각을 함께 기록합니다.

### 1-2. 서비스 이용 과정에서 생성되는 정보

| 항목 | 내용 | 이용 목적 |
|---|---|---|
| 매칭 신청 내역 | 지역, 식사 날짜, 시간대, 성별 조건, 선호 음식, 2인 허용 여부, 상태, 소속 그룹 | 그룹 편성, 중복 신청 차단, 만료 처리 |
| **채팅 메시지** | 그룹 채팅방에서 보낸 대화 내용과 보낸 시각 | 지난 대화 다시 보기, **신고 사실 확인** |
| 신고 내역 | 신고자, 신고 대상, 사유, 상세 내용, 접수·처리 시각 | 신고 처리, 반복 위반 확인 |
| 차단 내역 | 차단한 사람, 차단당한 사람, 차단 시각 | 이후 매칭에서 두 사람을 같은 그룹에 넣지 않기 위함 |

> **채팅 대화는 서버에 저장됩니다.** 실시간으로 흘러가고 사라지는 것이 아니라 데이터베이스에 남으며,
> 이용자가 지난 대화를 다시 볼 수 있고 **신고가 접수되면 운영자가 사실 확인을 위해 열람할 수 있습니다.**
> 이 사실을 전제로 채팅방을 이용하십시오. 채팅방에서 연락처·주소·직장 등 개인정보를 공유하지 않기를 권장합니다.

## 2. 다른 이용자에게 공개되는 범위

매칭이 성사되면 같은 그룹의 이용자에게 **닉네임과 프로필 이미지만** 표시됩니다.

**이메일, 출생연도, 성별, 신고·차단 내역은 다른 이용자에게 공개되지 않습니다.**
성별과 출생연도는 매칭 조건 판정에만 쓰이고 화면에 노출되지 않습니다.
누가 나를 차단했는지, 누가 나를 신고했는지는 어떤 경우에도 알려주지 않습니다.

## 3. 개인정보의 이용 목적

1. 회원 가입·로그인·본인 확인
2. 만 19세 이상 여부 확인
3. 조건에 맞는 이용자를 묶는 매칭 그룹 편성
4. 그룹 채팅 제공 및 대화 기록 보관
5. 신고 처리, 차단 반영, 이용 제한 등 안전 조치
6. 서비스 운영 통계 확인(지역·시간대별 신청 수, 매칭 성사율 등)

수집한 정보를 위 목적 외의 용도로는 이용하지 않습니다.
광고·마케팅 목적의 이용과 발송은 하지 않습니다.

## 4. 제3자 제공과 처리 위탁

1. **이용자의 개인정보를 제3자에게 제공하거나 판매하지 않습니다.**
2. 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우에만 예외적으로 제공합니다.
3. 서비스 운영에 필요한 인프라(데이터베이스·서버 호스팅 등) 이용 현황은 **(위탁 현황: 출시 전 확정)**입니다.

## 5. 보유 기간과 파기

| 정보 | 보유 기간 |
|---|---|
| 이메일·비밀번호·닉네임·프로필 이미지 | **탈퇴 즉시 익명 처리.** 복구할 수 없습니다 |
| 성별·출생연도 | 탈퇴 후에도 남습니다. 위 식별 정보가 지워져 **특정 개인을 알아볼 수 없는 상태**가 됩니다 |
| 매칭 신청 내역 | 탈퇴 시 진행 중인 신청은 취소되고 그룹에서 나갑니다. 기록 자체는 익명 상태로 남습니다 |
| 채팅 메시지 | 익명 상태로 남습니다. 대화 상대의 기록이기도 하고, 신고 사실 확인의 근거가 되기 때문입니다. 발신자는 "탈퇴한 사용자"로 표시됩니다 |
| **신고 내역** | **탈퇴 후에도 (보존 기간: 출시 전 확정) 동안 보존** |
| 로그인 토큰 | 로그아웃·탈퇴 시 즉시 무효화 |

**신고 내역을 탈퇴 후에도 보존하는 이유**: 신고당한 이용자가 탈퇴로 기록을 지우고 다시 가입할 수 있다면
신고 제도가 아무것도 막지 못하기 때문입니다. 보존하는 신고 기록에는 신고 대상을 식별하기 위한
최소한의 정보만 남깁니다.

법령이 별도의 보존 기간을 정한 경우에는 그 기간을 따릅니다.

## 6. 이용자의 권리와 행사 방법

| 권리 | 방법 |
|---|---|
| 내 정보 조회 | 프로필 화면 |
| 닉네임·프로필 이미지 변경 | 프로필 화면 |
| 이메일·비밀번호 변경 | 회원정보 변경 화면 |
| **성별·출생연도 변경** | **불가능합니다.** 성별 조건 매칭과 성인 여부 판정의 근거라, 변경을 허용하면 두 장치를 모두 우회할 수 있게 됩니다 |
| 탈퇴 | 탈퇴 기능. 5절의 보유 기간에 따라 처리됩니다 |
| 차단 해제 | 현재 제공하지 않습니다. 차단은 안전 기능이므로 되돌리기 어렵게 두었습니다 |

## 7. 만 19세 미만의 이용

**만 19세 미만은 가입할 수 없으며, 이에 따라 아동·청소년의 개인정보를 수집하지 않습니다.**
가입 시 출생연도로 확인하며, 만 19세 미만으로 판정되면 가입이 거부됩니다.
미성년자가 허위 출생연도로 가입한 사실이 확인되면 계정과 관련 정보를 삭제합니다.

## 8. 안전성 확보 조치

1. 비밀번호는 해시 처리하여 저장하며 운영자도 원문을 알 수 없습니다.
2. 회원가입·로그인·토큰 재발급을 제외한 모든 기능은 인증된 이용자만 사용할 수 있습니다.
3. 채팅방은 해당 그룹의 구성원만 입장·발신·기록 조회가 가능하며, 그룹에서 이탈하면 접근 권한을 잃습니다.
4. 로그아웃·비밀번호 변경 시 기존 로그인 토큰을 무효화합니다.

## 9. 방침의 변경

이 방침을 변경할 때는 시행일 전에 서비스 내에 공지합니다.
수집 항목이나 이용 목적을 추가하는 변경은 별도로 동의를 받습니다.
